## Design summary

- **Typeface**: Plus Jakarta Sans, loaded via Google Fonts, replacing the
  system stack — geometric, rounded, premium.
- **Palette**: deepened forest greens (#052514 → #58C97D) plus a restrained
  champagne-gold accent (#C9A227) used only on premium touches — the peak
  bar in "weekly spending", the "done" badge, taglines, the icon set.
  Background is now a warm ivory with two very soft corner glows instead of
  flat gray-green.
- **Hero cards**: "Left this month" (Home), "Monthly income" (Plan) and
  "Total saved" (Save) are now dark gradient glass cards (forest → deep
  green, gold + mint glow) — the flagship treatment, used consistently
  wherever a big number is the headline.
- **Smart insight card**: same dark treatment, echoing the reference app's
  AI-assistant card — the signature element. A ✨ sits before the heading.
  Done via a scoped CSS variable override (`#cardInsight { --ink: #fff; }`)
  so nothing in the JS/HTML needed to change.
- **Grow / Debts summary cards**: a lighter touch — a gold-to-green hairline
  accent along the top edge, for variety without going fully dark
  everywhere.
- **Category colors**: swapped for a muted jewel-tone set (emerald, gold,
  terracotta, steel blue, plum, teal…) — flows into category icons, budget
  bars, and the "where it goes" breakdown automatically.
- **App icon & splash**: deep forest tile with a white silhouette mark
  (previously a plain white tile) — every density, legacy and adaptive,
  round and square. Splash is now a dark gradient with the wordmark in
  white instead of a flat white screen.
- **Bottom nav**: floating frosted pill bar instead of a bar docked to the
  screen edge; the active tab gets a gradient pill highlight.
- **FAB / buttons**: pill-shaped, richer gradients with a soft glow shadow.
- **Every interactive element now has explicit tactile feedback**: a
  press-down scale + tint on tap for every button, row, and card
  (`catrow`, `txrow`, `setting`, `catbar`, `stat`, `grow-row`, segmented
  controls, icon pickers, quick-amount chips…), a gentle hover lift on
  devices with a real pointer, and visible `:focus-visible` rings for
  keyboard/accessibility use. Nothing tappable is left without a response.
- **Forms**: rounded inputs with a soft green focus ring instead of a hard
  border-color swap.
- **Modal sheet / toast / profile card**: matching radius, shadow and
  gradient touches for consistency.

## A note on the previews

The two screenshots were rendered with a lightweight, older headless engine
(no live JS execution), so the numbers/lists show empty rather than sample
data — they're there to confirm layout, spacing and color, not to be a full
functional demo. Everything JS-driven (totals, category math, goals, debts)
is covered separately by the project's own test suite, which passes in
full. Open `index.html` in a real browser locally to see it fully live
before you push.
